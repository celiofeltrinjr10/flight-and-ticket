Buscas sob demanda

Rotas e datas pedidas pelo formulário do GitHub. Repetir a mesma busca atualiza a página e acumula histórico.

Como fazer uma nova busca
  1. Abra GitHub → Actions → Busca sob demanda (também funciona no app do GitHub no celular).
  2. Toque em Run workflow e preencha: origem e destino com 3 letras (aeroporto como BCN ou cidade como LON, SAO, RIO), ida e volta como 2026-11-10 ou 2026-11-01 a 2026-11-15 (volta vazia = só ida).
  3. Confirme em Run workflow. Leva ~1 min por 8 datas; o resultado aparece aqui. Máximo de 150 datas por busca.
